SIPster 🍻

Titel? Interpret? Jahr? Wer errät, trinkt nicht.

1. YouTube-Zugang

SIPster sucht Songs selbst über die YouTube-Suche, damit auch du als Gastgeber:in nicht vorher weißt, was kommt. Dafür braucht es einen kostenlosen YouTube Data API v3-Key (Google Cloud Console → API aktivieren → Anmeldedaten → API-Key erstellen).

2. Spieler:innen (min. 2)

    Regeln

    • Jede:r startet mit 4 Leben (max. 4).
    • Titel oder Interpret korrekt genannt → kein Leben verloren.
    • Weder Titel noch Interpret genannt → ein Leben weg (= trinken).
    • Zusätzlich das richtige Jahr genannt → Extra-Leben (Deckel bei 4).
    • Songpool: 0 Songs, es wird zufällig & ohne Wiederholung gezogen.

    Songs übrig: 0

    🎧 Lied läuft – nicht hinschauen, nur zuhören!
